# 01 学生成绩排序

## 题目

用结构体数组存 5 个学生（姓名 + 成绩），输入后按成绩从高到低排序并输出。

## 涉及的知识点

- `typedef struct` 定义自己的类型
- 结构体数组 + 下标访问（`a[k].name`）
- `%s` 与 `%d` 的区别、`scanf` 里 `&` 的取舍
- **结构体整体赋值**：`tmp = a[j]` 一次复制所有成员
- 冒泡排序 + 降序方向（前面比后面小就交换）

## 踩过的坑（都真踩了）

1. `scanf("%s", a[k].score)` —— 成绩是 int，要用 `%d`，还要加 `&`
2. 交换写成 `a[j+1] = a[j]` —— tmp 白存了，元素直接丢一个
3. 比较用 `>` —— 那是升序；降序要 `<`
4. 输出用 `%s` 打 int —— 该用 `%d`
5. 类型定义后面多写了一个变量名，等于顺手定义了全局变量

## 编译

```bash
gcc -Wall -Wextra -o sort student_sort.c
```

`-Wall -Wextra` 下零警告。
