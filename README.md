## 编译方式

```bash
gcc -Wall -Wextra -o program 源文件.c
```

所有程序都在 `gcc -Wall -Wextra` 下保持零警告。

## 学习路线

C 基础 → 数据结构（用 C 实现）→ 寒假做完整项目 → 大二上找实习。
